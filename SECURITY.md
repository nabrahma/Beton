# Security Policy

## Supported versions

Béton is pre-1.0. Security fixes are applied to the latest published minor
version of each `@beton-ui/*` package and to the latest registry output.

## Reporting a vulnerability

Please do not open a public issue for security problems.

Report vulnerabilities privately through
[GitHub Security Advisories](https://github.com/nabrahma/Beton/security/advisories/new).
Include a description, reproduction steps, and the affected package or
component.

You can expect an acknowledgement within 72 hours. Once a fix is available, the
advisory will be published with credit to the reporter unless you prefer to
remain anonymous.
